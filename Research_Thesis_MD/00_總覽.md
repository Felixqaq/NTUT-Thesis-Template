## 目前最適合寫成論文的主線

建議論文主題以 `COPDClassification` 為主：

> Chest CT-based COPD classification using automatic lung segmentation, quantitative pulmonary biomarkers, and neural network classification.

可用中文題目：

> 基於胸部電腦斷層影像之 COPD 自動分類：結合肺部自動分割、影像定量特徵與神經網路模型

目前最完整的研究閉環如下：

1. 醫院 DICOM 轉換為 NIfTI/HU 影像。
2. 以 3D Slicer / MONAI Auto3DSeg 產生肺葉、血管、氣管等 segmentation label。
3. 使用 AeroPath 嘗試氣道 segmentation，並產生 OBJ 或 NIfTI airway 結果。
4. 使用 `COPDAnalyzer` 從 CT + label + airway 中計算 COPD 定量特徵。
5. 使用 12 個影像特徵訓練 PyTorch MLP 分類模型。
6. 使用 5-fold cross validation 評估 COPD vs normal。
7. 分析 confusion matrix、ROC、false negative 個案與特徵分布。

## 寫論文時需要特別小心的點

1. `pft.json` 的 GOLD 分組主要根據 FEV1 % predicted，論文中不能直接宣稱所有 GOLD 1 都是 COPD。正式 GOLD COPD diagnosis 通常還需要 post-bronchodilator FEV1/FVC < 0.7。
2. 主模型是 binary classification：normal vs COPD/abnormal。它不是目前真正完成的 GOLD 1-4 severity classification。
3. AeroPath 目前大量輸出是 OBJ，主分類程式偏好 airway NIfTI；若只有 OBJ，WA% 可能退回 label 7 或無法完全代表 airway wall。
4. EmphysemaSeg 的 lobe label 定義與 `COPDAnalyzer` 的 lobe label 定義不同，不可直接混用。
5. `CTEmphysemaScore` 缺少正式權重與視覺分數標籤，適合作備案或相關工作，不適合作主結果。
6. `nnMamba` 目前是模型框架與未接完資料，不可寫成已完成 COPD 實驗結果。
7. `Dataset` 中有很多外部資料與非 COPD 主題資料，論文主要資料來源應清楚界定為醫院 54 例主實驗。
